# Y2K 撞色剪贴海报视觉系统

生成或修改海报时读取本文件。

## 配色组合

每张海报选一组主背景色与描边色，第三色只做少量点缀：

| 气质 | 高饱和背景 | 主体描边 | 小面积点缀 |
|---|---|---|---|
| 电光冷感 | 钴蓝 `#2447FF` | 酸性黄 `#F2FF57` | 黑或白 |
| 酸甜玩味 | 青柠绿 `#A8EF28` | 泡泡粉 `#FF72C8` | 炭黑 |
| 夜店复古 | 深洋红 `#981052` | 淡黄绿 `#E7F6A0` | 纯白 |
| 数码冲突 | 电紫 `#6D24FF` | 荧光橙 `#FF6B22` | 银灰 |
| 千禧清亮 | 亮青 `#00C7D9` | 热粉 `#FF3E9E` | 奶油白 |
| 火焰张力 | 燃烧橙 `#FF5A1F` | 电光紫 `#5B2EFF` | 黑或白 |
| 夜光赛博 | 墨黑 `#111111` | 霓虹青 `#00F0FF` | 银白 |
| 闪光运动 | 闪光黄 `#FFD400` | 皇家蓝 `#2447FF` | 炭黑 |

- 深色或黑白主体优先亮背景和浅描边。
- 浅色主体优先深背景和酸性亮描边。
- 主体含重要品牌色时，背景避开相近色相，确保轮廓分离。
- 背景占绝对主导；不要让背景、描边和装饰拥有同等面积。

## 撞色推荐方法

在询问用户前先完成以下判断，再给出一个推荐和两个差异明显的备选：

1. **主体明暗**：深色主体优先亮描边；浅色主体优先深色或高纯度描边。
2. **主体主色**：避开与主体大面积同色的背景；优先选主色的互补色、分裂互补色或冷暖反向色。
3. **识别色保护**：商品包装、宠物花纹、服饰标志等关键颜色不得被整体调色吞没。
4. **画面情绪**：活泼可选电光冷感或酸甜玩味；甜酷可选千禧清亮；强张力可选火焰张力；冷峻可选夜光赛博。
5. **轮廓分离**：背景与描边不仅要色相不同，也要有足够明度差；若灰度预览中轮廓消失，改用更亮或更暗的描边。

推荐说明应明确关联当前图片，例如“主体以深发色和浅灰服装为主，酸性黄描边能保住发丝轮廓，钴蓝背景会让肤色更突出”。不要只说“更好看”。

## 构图路由

- 构图、正负形、文字尺度和装饰锚点统一遵循 [layout-system.md](layout-system.md)。本节只提供姿态路由。
- 单主体站姿：主体置中或略偏下，标题在头肩外侧，星形沿对角线分布。
- 单主体半身或近景：沿用原图裁切逻辑并允许主体撑满画面；让头发、肩部或躯干下缘贴边或出血，把标题放进脸部朝向反侧或肩颈外侧的集中负空间，不为追求完整轮廓而缩小主体。
- 单主体坐姿或动物：主体稍放大并偏下，上方放标题，后方用一个大星芒支撑。
- 双人或主体组：保留互动和相对位置，用同一条外描边把组合并为整体；装饰放在组外。
- 商品或普通物体：保持真实比例，可轻微旋转 3–8 度；用放射星芒或点阵强调轮廓，不虚构功能标签。
- 横向姿态：允许主体斜跨竖版画面，文字沿剩余长边分布，不扭曲主体。

## 质感等级

生成前必须让用户从以下三个等级中确认一个。未确认时不得生成。三个等级是固定配方，不把其中的元素任意交叉组合。

### 干净印刷

- 适合强调撞色、服装细节和清晰轮廓。
- 高饱和纯色保持约 92%–96% 的干净视觉面积。
- 只添加一层非常细密、均匀、低对比度的纸张颗粒，视觉强度约 2%–4%。
- 不添加明显划痕、折痕、污渍、边缘磨损、粗颗粒或复印机色斑。

### 标准 Y2K（默认推荐）

- 适合大多数青年杂志剪贴海报；兼顾统一感和旧印刷触感。
- 高饱和纯色保持约 88%–92% 的干净视觉面积。
- 固定叠加细密纸张颗粒，视觉强度约 4%–7%；再加轻微、均匀的丝网印刷噪点，视觉强度约 2%–4%。
- 全画面只允许 1–3 条低对比度细划痕；不添加明显折痕、污渍、大面积褪色、边缘破损或粗颗粒团块。
- 主体与背景共用相同颗粒尺度；脸部、眼睛和产品关键细节上的纹理强度减半。

### 重度复古

- 适合用户明确想要复印刊物、地下杂志或强烈做旧效果时使用。
- 高饱和底色仍需保持约 75%–85% 的可见纯色面积，不能被灰尘和磨损覆盖成脏灰色。
- 添加中等粗度复印机噪点，视觉强度约 8%–12%，以及克制的边缘磨损，视觉强度约 3%–6%。
- 使用 1–3 条自然的边缘折痕。每条折痕从画布某一边缘进入，主要可见范围约为画布短边的 12%–35%；边缘处最清楚，向画面中心连续、柔和地衰减，在进入中央区域前降至几乎不可见。中央约 45%–55% 的主要画面区域不应出现清晰折痕。
- 折痕只作用于背景层，必须在主体外描边和主体照片下完全隐藏，也不得覆盖主标题、辅助文字或星芒。折痕不能成为独立装饰或第二视觉。
- 折痕方向可为横向、纵向或约 15–65 度的斜向；同一张画面不强制横竖同时出现，禁止机械十字、井字或贯穿全画面的网格结构。折痕使用低对比度明暗双线或柔和压痕边缘，明暗变化保持克制。
- 折痕之外最多再加 1 条明显划痕；禁止同时堆叠大量污渍、色斑、破洞和扫描线。折痕仍是重度复古的识别特征，但不能用强烈线条压住主体。
- 脸部、眼睛、文字和产品关键识别区域的做旧强度不超过背景的一半。

### 批次一致性

- 同一批海报默认共用同一个质感等级、同一颗粒尺度、同一噪点密度、相近折痕对比度和划痕数量，只改变撞色和版式。折痕的具体方向与进入边缘可以随构图变化，避免复制成相同模板。
- 星芒不增加独立选择步骤。每张海报最多使用 1 个主星芒和 0–2 个次星芒；主星芒根据背景明度自动选择一种结构：深色背景用浅色核心加撞色外层，中等明度背景用米白或浅中性色网点，高明度或荧光背景用黑色/深色填充加描边色网点或内层。次星芒优先使用与主体描边同色的纯色。所有颜色只能来自当前背景、描边、文字及黑白米色；不引入游离新色。
- 黑色只能作为明确的填充层、阴影层或网点底色，不能成为随意添加的通用描边。当主体、文字和背景已经形成三层以上清晰对比时，主星芒退回与主体描边同色的无边框纯色。单张海报只使用一种主星芒语言；同一批保持相同的层级逻辑，但可依各图背景明度选择适配结构。
- 不因照片本身明暗不同而擅自切换质感等级；必要时只调整纹理明度，不能改变纹理类型或强度档位。
- 硬边几何装饰保持清晰；所有等级都禁止柔和渐变光晕、精致奢华、光滑 3D 金属字和可爱贴纸风。
