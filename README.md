# y2k-pop-poster

由 **koinu** 制作的 Codex Skill：识别照片中的主要人物、动物、商品、植物或其他物体，将主体精确提取后制作成高饱和撞色描边、短文字、星芒与波点装饰组成的 Y2K 剪贴海报。

## 主要能力

- 自动判断并锁定画面主主体，保留人物身份、动物花纹、商品结构与细小轮廓。
- 生成前只确认两项：**撞色方案**与**背景质感等级**，避免选项过多。
- 提供干净印刷、标准 Y2K、重度复古三档固定质感。
- 根据全身、半身或近景自动控制主体比例、留白和安全边距。
- 让星芒与肩部、腰胯、膝盖、脚部或动作折点形成遮挡互动，而不是随机贴装饰。
- 根据背景明度和画面复杂度自动选择纯色、双色、网点或中性色主星芒；次星芒优先与主体描边同色，并且不引入确认配色之外的新颜色。
- 自动建立主标题、辅助短句和微型标签的字体层级。

## 安装

将本仓库完整放入 Codex 的 skill 目录，并保持文件夹名为：

~~~text
.codex/skills/y2k-pop-poster/
~~~

核心入口为 <code>SKILL.md</code>。<code>references/</code> 包含配色、质感与排版规则，<code>agents/openai.yaml</code> 包含 Codex 界面元数据。

## 使用

上传一张或多张照片，然后调用：

~~~text
使用 $y2k-pop-poster 把上传照片制作成 Y2K 撞色描边海报。
~~~

Skill 会先分析主体，并一次性提供：

1. 一个推荐撞色方案；
2. 两个差异明显的备选方案；
3. 干净印刷、标准 Y2K、重度复古三个质感等级。

同时确认撞色与质感后才会生成。例如：

~~~text
推荐＋标准
~~~

## 适用范围

适合照片转海报、主体抠图、千禧复古拼贴、人物或动物视觉、小红书竖版海报。不适合只需要透明底抠图、写实修图或左右挖空移位版式的任务。
